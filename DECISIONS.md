# Decisions

One line each: decision, reason.

- Repo lives in `NorthBots/northbot/` next to the build prompt, so the prompt file stays out of the repo.
- Node 22 is the target (Docker images, CI, `engines`); local dev also runs on Node 24, which is compatible.
- zod 3 (not 4) with `fastify-type-provider-zod@4`, because that pairing gives zod validation + OpenAPI generation from one schema.
- Workspace packages export TypeScript source (`exports: ./src/index.ts`); the server is bundled with tsup, which inlines them, so no per-package build step.
- The first migration is a hand-written `CREATE EXTENSION vector`, and later migrations are generated by drizzle-kit.
- Migrations run on boot under a Postgres advisory lock, so several server instances can start together safely.
- Web container is nginx serving the Vite build and proxying `/api/*` (prefix stripped) and `/v1/*` to the server, which keeps one origin for cookies.
- Server tests run against the real compose Postgres (no mocks for the DB), one file at a time.
- Acceptance scripts are bash; on Windows they run under Git Bash.
