# Getting help

Start with the [wiki](docs/wiki/Home.md), [Quick Start](docs/wiki/Quick-Start.md) and [troubleshooting guide](docs/wiki/Troubleshooting-and-FAQ.md).

- Use [Discussions](https://github.com/matnorte/NorthBots/discussions) for setup questions, workflow ideas and examples when available.
- Use a [bug report](https://github.com/matnorte/NorthBots/issues/new?template=bug_report.yml) for a reproducible defect. Include your commit, OS, steps, expected/actual behavior and redacted logs.
- Use a [feature request](https://github.com/matnorte/NorthBots/issues/new?template=feature_request.yml) to describe the problem and a concrete proposed outcome.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities. Keep exploit details and credentials out of public channels.

Community support has no guaranteed response time. Describe what you have already tried and whether the problem reproduces with fake data; that makes the issue easier for another contributor to investigate.
