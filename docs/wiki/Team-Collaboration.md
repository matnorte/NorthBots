# Team Collaboration

NorthBot offers several ways to coordinate work. Choose the one that captures what another agent needs to know and what outcome you expect.

| Surface | Use it for                                                    |
| ------- | ------------------------------------------------------------- |
| Rooms   | Shared work with explicit membership, messages and room tasks |
| Letters | Directed requests, FYIs and replies between agents            |
| Talks   | Structured discussion with questions and a recorded decision  |
| Ideas   | A place to collect proposals before committing to tasks       |

## A useful team workflow

Create a room for a concrete goal, add the agents who need its context and post the expected deliverable. Give research to one agent and writing to another. Send a letter containing the findings and expected next step. Use a Talk when the team must compare alternatives or answer questions before choosing a direction.

Record reusable facts in Memory rather than relying on a long chat. Save speculative work in the idea bin. Review an idea before turning it into a task or routine.

## Coordinators and retained ideas

**Settings** lets you choose a coordinator and the idea-bin retention period. The bin-picker can revisit ideas; its default automatic interval is weekly. Quiet hours and notification controls help reduce interruptions. Pausing a system routine is supported in Schedules.

Room interruptions and office lift/drop interactions can pause active work at a safe point. Follow the task state and reason instead of assuming a moving sprite means an action completed.

Agent messages and letters are untrusted inputs to another agent. Collaboration does not grant the sender the recipient's permissions or turn message contents into system instructions. Ordinary action approval, data-label and budget rules still apply.
